---
title: "Spec drift check parks a sub-ticket for its own sibling's merge"
---

Found while building #65: the build-start test-drift check (#44, `_test_drift` in `factory/cli.py`) parks a sub-ticket for "drift" made by its own parent's merged sibling.

## What happened

- T-0040.1 (part A) merged as 2ad4d8c52. It created `tests/factory/test_drive.py` and changed `factory/cli.py`, which the design names.
- T-0040.2 (part B) was then parked before its first implementer run with: `BLOCKED from harness: spec drift: tests/factory/test_drive.py changed by 2ad4d8c52 since spec v4 was written at 37848dbb0`.
- This is not drift. The plan has part A create that file, and part B's sub-ticket says part B may import from it.

## Cause

`_test_drift` walks every first-parent commit from the approved version's integration head to the tip. It does not exclude the `main_after` merges of the parent's own merged sub-tickets. `_sibling_drift` and the Tests-to-change sibling check (cli.py, around line 258) already treat sibling merges as expected.

## Fix

Skip first-parent commits that are a merged sibling's `merge.main_after`. Add a suite case: in a two-part plan where part A adds a test file and touches a design-named file, part B starts without a drift park. The existing drift cases must still fire for commits from other tickets.

Workaround until then: `resolve <sub> --ruling F` (applied to T-0040.2).


## Comment

Second instance, T-0040.3 (part C): the same false positive, at `run start` this time. The build script's clerk re-encoded the JSON refusal as a Python dict, so the script parked it as `harness-bug: run start implementer: …` instead of verbatim. No `resolve` option accepts a harness-bug park from ready-for-implementer: `--ruling` needs ESCALATE/BLOCKED, and `--redispatch` needs a park from the checks. With the operator's go, the park reason was restored to the refusal's text by hand, logged as `park.corrected`, then ruled. Add to this issue's fix: a resolve route for a harness-bug park before an implementer run. The clerk half goes away with #65's driver.
