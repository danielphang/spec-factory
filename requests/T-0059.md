---
title: "The gate replays every current-truth scenario, so a change that breaks another capability's scenario cannot merge"
---

**Problem, for the gate:** a change can break behaviour that an earlier ticket made part of current truth, and still merge. Current truth holds 284 runnable scenarios across 15 capabilities in this store. Each is a command plus the output it must print. Nothing runs all of them:
- the gate commands are `git diff --check` and the pytest suite;
- the verifier runs only the acceptance its own spec lists.

**Evidence:**
- On the Nanobot target, a change made outside the factory broke 3 current-truth scenarios (#87). Nobody saw it until a later ticket's work.
- T-0049's spec writer ran all 80 `harness-docs` scenarios by hand to show that only three changed.
- #113: one scenario fails under macOS's `/bin/sh` whatever the code does, so today a scenario's result depends on the shell that happens to run it.

**Requirements from the operator (2026-10-19):**
- **A. A command that runs current truth.** `factory truth check` runs every scenario's WHEN in the checkout under test, always under `bash`. It compares the output with the THEN by the rule the verifier already uses for an exact print. It prints pass or fail for each scenario, a total, and exits non-zero on any failure. `--capability <name>` limits the run.
- **B. A ticket's own changes count.** A ticket that legitimately changes behaviour MODIFIES or REMOVES the scenarios it changes. When the check runs on that ticket's branch, it uses current truth with the ticket's approved delta applied, so the old form of a scenario the ticket changes is not reported as a regression. The spec says how. Archive's own fold is the obvious source.
- **C. Scenarios that cannot run mechanically** (a THEN in prose, or one needing a live service) are listed as skipped with a reason and counted, never silently passed.
- **D. In the gate.** This instance adds the check to `gate_commands`. Adopting it on another target is that target's owner's decision.
- **E. Its cost is measured.** The check reports its wall time. The spec states the figure on this repo, against the suite's current 119 s.

**Serves:** the north star's constraint that escaped defects do not rise (#116).

**Order:** after the fix for #113, so the first run is clean.
